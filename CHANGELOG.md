## [0.1.0] - 2026-07-26

### Added
- CSV parser and writer — `csv-read`/`csv-read-string`/`csv-read-row` and
  `csv-write`/`csv-write-string`/`csv-write-row`, plus `csv-fold` for
  streaming row processing
- Pure Scheme implementation, no C dependencies or build step
- CI workflow for automated testing
